# KAARTHIK — Personal Portfolio

> **Full Stack Web & App Developer**  
> An interactive 60 FPS HTML5 Canvas scrollytelling web experience featuring inertial momentum scroll physics, an interactive developer terminal emulator, and a tactical weapons of choice tech arsenal.

---

## 🌟 Key Highlights & Features

- 🎞️ **60 FPS Canvas Scrollytelling Engine**: 180 high-fidelity WebP frames scrubbed smoothly via HTML5 Canvas with Framer Motion `useSpring` inertia damping (`stiffness: 110, damping: 26`).
- ⚡ **Lenis Momentum Scrolling**: Inertia scrolling synchronized directly with the browser's `requestAnimationFrame` render loop.
- 💻 **Interactive Developer Terminal**: Fully functional interactive bash shell emulator (`whoami`, `skills`, `projects`, `stack`, `contact`, `clear`) with quick-execute command pills.
- 🛡️ **Tactical Weapons of Choice Matrix**: Technical spec loadouts covering Full-Stack Web, Cross-Platform Mobile (Flutter / React Native), Backend & APIs (Node.js / Express), and Database Infrastructure (MongoDB / PostgreSQL).
- 🔊 **Zero-Asset Synthetic Audio**: Programmatic micro-interaction audio feedback built with the native browser Web Audio API (`AudioContext`, `BiquadFilterNode`, `OscillatorNode`) — zero external `.mp3` files required.
- 🎯 **Fluid Spring Cursor**: Dual-ring trailing cursor with spring physics that magnetically snaps and expands over clickable elements.
- 📱 **Fully Responsive**: Optimized for ultra-wide displays, laptops, tablets, and mobile devices.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.17+ or higher
- npm / yarn / pnpm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
```

2. Install dependencies:
```bash
npm install
```

3. Start the local development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
